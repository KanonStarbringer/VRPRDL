#### Structure of the instance files  #### 
General parameters: 
number_of_customers    number_of_locations    time_horizon    vehicle_capacity

Customer schedules: 
...
customer_id demand	location_id_1 [time-opening,time-closing] location_id_2 [time-opening,time-closing] ...
...
 
Location coordinates:
...
location_id 	 x_coordinate y_coordinate
...

Travel time matrix: 
...
(origin_location_id,destination_location_id) travel_time
...
